# Positive und negative Zahlen

> [!info] **Lernziele**
> Nach diesem Kapitel solltest du:
> - Positive und negative Zahlen sicher unterscheiden können
> - Vorzeichen korrekt interpretieren und verwenden
> - Rechenregeln für Vorzeichen anwenden können
> - Alltagsbeispiele für negative Zahlen kennen

---

## Überblick

Positive und negative Zahlen ermöglichen es, Richtungen und Gegensätze mathematisch auszudrücken: Gewinne und Verluste, Temperaturen über und unter null, Höhen über und unter dem Meeresspiegel. Das Vorzeichen einer Zahl gibt an, auf welcher Seite der Null sie liegt.

---

## Definition

### Positive Zahlen

**Positive Zahlen** sind alle Zahlen, die größer als Null sind:
- Liegen auf dem Zahlenstrahl **rechts** von der Null
- Haben das Vorzeichen $+$ (kann weggelassen werden)
- Beispiele: $1$, $3{,}5$, $\frac{2}{3}$, $\pi$

### Negative Zahlen

**Negative Zahlen** sind alle Zahlen, die kleiner als Null sind:
- Liegen auf dem Zahlenstrahl **links** von der Null
- Haben das Vorzeichen $-$ (muss geschrieben werden)
- Beispiele: $-1$, $-3{,}5$, $-\frac{2}{3}$, $-\pi$

### Die Null

Die **Null** ist weder positiv noch negativ – sie ist der Ursprung, der positive und negative Zahlen trennt.

```
    negative Zahlen          positive Zahlen
           ↓                       ↓
    ←──┬────┬────┬────┬────┬────┬────┬────┬──→
      -3   -2   -1    0    1    2    3    4
                      ↑
                weder positiv
                noch negativ
```

## Vorzeichen

Das **Vorzeichen** steht vor einer Zahl und gibt an, ob sie positiv oder negativ ist:

| Vorzeichen | Bedeutung | Beispiel |
|------------|-----------|----------|
| $+$ (Plus) | Positiv | $+5$ oder einfach $5$ |
| $-$ (Minus) | Negativ | $-5$ |

> [!note] **Konvention**
> Bei positiven Zahlen wird das Pluszeichen meist weggelassen:
> $$+7 = 7$$
> Bei negativen Zahlen muss das Minuszeichen **immer** geschrieben werden.

## Alltagsbeispiele

### Temperatur

| Temperatur | Bedeutung |
|------------|-----------|
| $+20°C$ | 20 Grad über dem Gefrierpunkt |
| $-5°C$ | 5 Grad unter dem Gefrierpunkt |
| $0°C$ | Gefrierpunkt von Wasser |

### Geld

| Betrag | Bedeutung |
|--------|-----------|
| $+500€$ | 500 Euro Guthaben |
| $-200€$ | 200 Euro Schulden |
| $0€$ | Kein Guthaben, keine Schulden |

### Höhe

| Höhe | Bedeutung |
|------|-----------|
| $+2962m$ | Zugspitze (über Meeresspiegel) |
| $-428m$ | Totes Meer (unter Meeresspiegel) |
| $0m$ | Meeresspiegel (Normalnull) |

### Zeitrechnung

| Jahr | Bedeutung |
|------|-----------|
| $+2026$ | 2026 n. Chr. |
| $-500$ | 500 v. Chr. |
| $0$ | Zeitenwende |

## Vergleichen von Zahlen

### Regeln zum Vergleichen

| Regel | Beispiel |
|-------|----------|
| Jede positive Zahl ist größer als 0 | $3 > 0$ |
| Jede negative Zahl ist kleiner als 0 | $-3 < 0$ |
| Jede positive Zahl ist größer als jede negative | $1 > -100$ |
| Von zwei negativen Zahlen ist die mit dem **kleineren Betrag** größer | $-2 > -5$ |

### Visualisierung auf dem Zahlenstrahl

```
    ←──┬────┬────┬────┬────┬────┬────┬────┬──→
      -5   -3   -1    0    1    3    5    7
       ↑                                   ↑
    kleiner                             größer

    -5 < -3 < -1 < 0 < 1 < 3 < 5 < 7
```

> [!tip] **Merkregel**
> Auf dem Zahlenstrahl gilt: **Weiter rechts = größer**.
> 
> Bei negativen Zahlen bedeutet das: Je „kleiner" die Zahl aussieht (z.B. $-2$), desto größer ist sie tatsächlich im Vergleich zu $-5$.

## Rechenregeln für Vorzeichen

### Addition und Subtraktion

| Regel | Beispiel |
|-------|----------|
| $a + (+b) = a + b$ | $5 + (+3) = 5 + 3 = 8$ |
| $a + (-b) = a - b$ | $5 + (-3) = 5 - 3 = 2$ |
| $a - (+b) = a - b$ | $5 - (+3) = 5 - 3 = 2$ |
| $a - (-b) = a + b$ | $5 - (-3) = 5 + 3 = 8$ |

> [!tip] **Merkregel: Minus und Minus ergibt Plus**
> „Zwei Minuszeichen heben sich auf":
> $$-(-a) = +a = a$$

### Multiplikation und Division

| Regel | Beispiel |
|-------|----------|
| $(+) \cdot (+) = +$ | $3 \cdot 4 = 12$ |
| $(+) \cdot (-) = -$ | $3 \cdot (-4) = -12$ |
| $(-) \cdot (+) = -$ | $(-3) \cdot 4 = -12$ |
| $(-) \cdot (-) = +$ | $(-3) \cdot (-4) = 12$ |

Die gleichen Regeln gelten für die Division.

> [!tip] **Merkregel: Vorzeichenregeln**
> - **Gleiche** Vorzeichen → Ergebnis **positiv**
> - **Verschiedene** Vorzeichen → Ergebnis **negativ**

### Zusammenfassung der Vorzeichenregeln

```
Multiplikation/Division:

  +  ·  +  =  +       "Plus mal Plus ergibt Plus"
  +  ·  -  =  -       "Plus mal Minus ergibt Minus"
  -  ·  +  =  -       "Minus mal Plus ergibt Minus"
  -  ·  -  =  +       "Minus mal Minus ergibt Plus"
```

## Häufige Fehler

> [!warning] **Achtung bei diesen Fehlern**
> 
> **Fehler 1:** $-3^2 \neq (-3)^2$
> - $-3^2 = -(3^2) = -9$
> - $(-3)^2 = (-3) \cdot (-3) = 9$
>
> **Fehler 2:** $-a$ ist nicht immer negativ!
> - Wenn $a = -5$, dann ist $-a = -(-5) = 5$ (positiv)
>
> **Fehler 3:** Vergleichen negativer Zahlen
> - $-2$ ist **größer** als $-5$, nicht kleiner!
