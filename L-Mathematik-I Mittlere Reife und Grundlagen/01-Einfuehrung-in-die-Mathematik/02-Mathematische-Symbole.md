## Überblick

Mathematik verwendet eine eigene Symbolsprache, die weltweit einheitlich ist. Diese Symbole ermöglichen es, komplexe Zusammenhänge kurz und präzise auszudrücken. Das Erlernen dieser Notation ist wie das Lernen eines Alphabets – es ist die Grundlage für alles Weitere.

---

## Grundlegende Rechenzeichen

### Die vier Grundrechenarten

| Symbol | Name | Bedeutung | Beispiel |
|--------|------|-----------|----------|
| $+$ | Plus | Addition | $3 + 5 = 8$ |
| $-$ | Minus | Subtraktion | $7 - 2 = 5$ |
| $\cdot$ oder $\times$ | Mal | Multiplikation | $4 \cdot 3 = 12$ |
| $:$ oder $\div$ oder $/$ | Geteilt | Division | $12 : 4 = 3$ |

> [!note] **Hinweis zur Schreibweise**
> In der höheren Mathematik wird meist der Malpunkt $\cdot$ verwendet. Das Kreuz $\times$ kann mit der Variable $x$ verwechselt werden. Bei Brüchen schreibt man $\frac{12}{4}$ statt $12 : 4$.

### Gleichheitszeichen und Verwandte

| Symbol | Name | Bedeutung | Beispiel |
|--------|------|-----------|----------|
| $=$ | gleich | linke und rechte Seite haben denselben Wert | $2 + 3 = 5$ |
| $\neq$ | ungleich | linke und rechte Seite sind verschieden | $3 \neq 5$ |
| $\approx$ | ungefähr gleich | Näherungswert | $\pi \approx 3{,}14$ |
| $:=$ oder $\coloneqq$ | definiert als | Definition einer Größe | $a := 5$ |

## Vergleichszeichen (Relationen)

| Symbol | Name | Bedeutung | Beispiel |
|--------|------|-----------|----------|
| $<$ | kleiner als | linke Seite ist kleiner | $3 < 7$ |
| $>$ | größer als | linke Seite ist größer | $9 > 4$ |
| $\leq$ | kleiner oder gleich | linke Seite ist höchstens so groß | $5 \leq 5$ |
| $\geq$ | größer oder gleich | linke Seite ist mindestens so groß | $8 \geq 6$ |

> [!tip] **Merkregel**
> Das Vergleichszeichen zeigt immer wie ein Pfeil zur kleineren Zahl:
> - $3 < 7$: Die Spitze zeigt zur $3$ (die kleinere Zahl)
> - $9 > 4$: Die Spitze zeigt zur $4$ (die kleinere Zahl)

## Klammerregeln

Klammern bestimmen die Reihenfolge der Berechnungen:

### Arten von Klammern

| Klammer | Name | Verwendung |
|---------|------|------------|
| $( \quad )$ | runde Klammern | Standard-Klammern |
| $[ \quad ]$ | eckige Klammern | äußere Klammern, Intervalle |
| $\{ \quad \}$ | geschweifte Klammern | Mengen |

### Rechenregel: „Klammer vor Punkt vor Strich"

1. **Klammern** zuerst auflösen (von innen nach außen)
2. **Punkt**rechnung (Multiplikation, Division)
3. **Strich**rechnung (Addition, Subtraktion)

**Beispiel:**
$$3 + 4 \cdot (2 + 5) = 3 + 4 \cdot 7 = 3 + 28 = 31$$

## Mengensymbole

Mengen sind Sammlungen von Objekten (Elementen):

| Symbol | Name | Bedeutung | Beispiel |
|--------|------|-----------|----------|
| $\in$ | Element von | gehört zur Menge | $3 \in \{1, 2, 3\}$ |
| $\notin$ | kein Element von | gehört nicht zur Menge | $5 \notin \{1, 2, 3\}$ |
| $\subset$ | Teilmenge von | alle Elemente sind enthalten | $\{1, 2\} \subset \{1, 2, 3\}$ |
| $\cup$ | Vereinigung | alle Elemente beider Mengen | $\{1, 2\} \cup \{3\} = \{1, 2, 3\}$ |
| $\cap$ | Schnittmenge | gemeinsame Elemente | $\{1, 2\} \cap \{2, 3\} = \{2\}$ |
| $\emptyset$ | leere Menge | Menge ohne Elemente | $\{1\} \cap \{2\} = \emptyset$ |

## Zahlenmengen-Symbole

Die wichtigsten Zahlenmengen haben eigene Symbole:

| Symbol | Name | Elemente |
|--------|------|----------|
| $\mathbb{N}$ | Natürliche Zahlen | $1, 2, 3, 4, \ldots$ |
| $\mathbb{N}_0$ | Natürliche Zahlen mit Null | $0, 1, 2, 3, \ldots$ |
| $\mathbb{Z}$ | Ganze Zahlen | $\ldots, -2, -1, 0, 1, 2, \ldots$ |
| $\mathbb{Q}$ | Rationale Zahlen | Alle Brüche $\frac{p}{q}$ |
| $\mathbb{R}$ | Reelle Zahlen | Alle Zahlen auf dem Zahlenstrahl |

---

## Weitere wichtige Symbole

| Symbol | Name | Bedeutung | Beispiel |
|--------|------|-----------|----------|
| $\sum$ | Summenzeichen | Summe mehrerer Zahlen | $\sum_{i=1}^{3} i = 1+2+3 = 6$ |
| $\prod$ | Produktzeichen | Produkt mehrerer Zahlen | $\prod_{i=1}^{3} i = 1 \cdot 2 \cdot 3 = 6$ |
| $\sqrt{\phantom{x}}$ | Wurzel | Quadratwurzel | $\sqrt{9} = 3$ |
| $\|x\|$ oder $|x|$ | Betrag | Abstand zur Null | $\|-5\| = 5$ |
| $\infty$ | Unendlich | unbegrenzt groß | $x \to \infty$ |
