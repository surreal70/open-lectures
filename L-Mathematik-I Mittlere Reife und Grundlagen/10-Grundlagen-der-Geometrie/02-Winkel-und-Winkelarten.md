# Winkel und Winkelarten

> [!info] Lernziele
> - Den Begriff des Winkels verstehen und erklären
> - Winkel korrekt bezeichnen und messen
> - Die verschiedenen Winkelarten unterscheiden
> - Winkel mit dem Geodreieck messen und zeichnen

## Was ist ein Winkel?

Ein **Winkel** entsteht, wenn sich zwei Strahlen (oder Halbgeraden) in einem gemeinsamen Punkt treffen.

### Bestandteile eines Winkels

```
              Schenkel a
             ╱
            ╱
           ╱
          ╱ α
         ●─────────────
      Scheitel    Schenkel b
```

| Bestandteil | Beschreibung |
|---|---|
| **Scheitel** | Der gemeinsame Punkt der beiden Strahlen |
| **Schenkel** | Die beiden Strahlen |
| **Winkelfeld** | Die Fläche zwischen den Schenkeln |

## Bezeichnung von Winkeln

### Mit griechischen Buchstaben

$$\alpha, \beta, \gamma, \delta, \varepsilon, \zeta, \eta, \varphi, ...$$

(Alpha, Beta, Gamma, Delta, Epsilon, Zeta, Eta, Phi)

### Mit drei Punkten

$$\angle ABC$$

- $B$ ist der Scheitelpunkt (steht in der Mitte!)
- $A$ liegt auf einem Schenkel
- $C$ liegt auf dem anderen Schenkel

## Maßeinheiten für Winkel

### Grad (°)

Ein **Vollwinkel** (vollständige Drehung) entspricht $360°$.

| Winkel | Grad |
|---|---|
| Vollwinkel | 360° |
| Gestreckter Winkel | 180° |
| Rechter Winkel | 90° |
| Halber rechter Winkel | 45° |

### Umrechnung

Ein Grad hat 60 Minuten ('), eine Minute hat 60 Sekunden (''):

$$1° = 60' = 3600''$$

> [!example] Beispiel
> $45°30' = 45° + \frac{30}{60}° = 45{,}5°$

## Winkelarten nach Größe

### Übersicht

```
Spitzer Winkel      Rechter Winkel     Stumpfer Winkel
     ╱                    │                  ╱
    ╱                     │                 ╱
   ╱                      │ ┐              ╱
  ╱ α                     │               ╱ α
 ●─────                   ●─────         ●─────
 0° < α < 90°           α = 90°       90° < α < 180°
```

```
Gestreckter Winkel     Überstumpfer       Vollwinkel
                         Winkel
                           ╲
 ●─────────────────        ╲              ●
        180°               ╲ α          ╱│
                           ●─────      ╱ │ 360°
                      180° < α < 360°  ──┘
```

### Tabelle der Winkelarten

| Winkelart | Größe |
|---|---|
| **Nullwinkel** | $0°$ |
| **Spitzer Winkel** | $0° < \alpha < 90°$ |
| **Rechter Winkel** | $\alpha = 90°$ |
| **Stumpfer Winkel** | $90° < \alpha < 180°$ |
| **Gestreckter Winkel** | $\alpha = 180°$ |
| **Überstumpfer Winkel** | $180° < \alpha < 360°$ |
| **Vollwinkel** | $\alpha = 360°$ |

## Winkel messen und zeichnen

### Winkel messen mit dem Geodreieck

1. Geodreieck so anlegen, dass der **Nullpunkt** auf dem Scheitel liegt
2. Eine **Grundlinie** liegt auf einem Schenkel
3. Den Wert am anderen Schenkel ablesen

> [!tip] Tipp
> Achte auf die richtige Skala! Bei spitzen Winkeln die innere, bei stumpfen die äußere Skala verwenden.

### Winkel zeichnen

1. Einen Schenkel zeichnen
2. Scheitel markieren
3. Geodreieck anlegen (Nullpunkt auf Scheitel, Grundlinie auf Schenkel)
4. Gewünschten Winkel markieren
5. Zweiten Schenkel durch die Markierung zeichnen

## Besondere Winkel

### Der rechte Winkel

- Hat genau **90°**
- Wird oft mit einem kleinen Quadrat gekennzeichnet: ┐
- Zwei Geraden, die einen rechten Winkel bilden, heißen **senkrecht** (orthogonal)

### Komplementwinkel

Zwei Winkel sind **komplementär**, wenn ihre Summe $90°$ ergibt:

$$\alpha + \beta = 90°$$

> [!example] Beispiel
> $\alpha = 35°$ → $\beta = 90° - 35° = 55°$

### Supplementwinkel

Zwei Winkel sind **supplementär**, wenn ihre Summe $180°$ ergibt:

$$\alpha + \beta = 180°$$

> [!example] Beispiel
> $\alpha = 120°$ → $\beta = 180° - 120° = 60°$

## Zusammenfassung

> [!abstract] Kernpunkte
> - Ein Winkel wird von zwei Strahlen mit gemeinsamem Scheitel gebildet
> - Winkel werden in Grad (°) gemessen
> - Winkelarten: spitz (< 90°), recht (= 90°), stumpf (> 90°), gestreckt (= 180°)
> - Komplementwinkel ergänzen sich zu 90°
> - Supplementwinkel ergänzen sich zu 180°

   - $\alpha = 47°$
   - $\beta = 90°$
   - $\gamma = 135°$
   - $\delta = 180°$
   - $\varepsilon = 270°$

2. Berechne den Komplementwinkel zu:
   - $25°$
   - $63°$
   - $45°$

3. Berechne den Supplementwinkel zu:
   - $40°$
   - $112°$
   - $90°$
