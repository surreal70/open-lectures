## Gehaltsberechnungen

### Brutto und Netto

| Begriff | Bedeutung |
|---------|-----------|
| Bruttogehalt | Gehalt vor Abzügen |
| Nettogehalt | Auszahlungsbetrag nach Abzügen |
| Abzüge | Steuern, Sozialversicherung |

### Beispielrechnung

**Aufgabe:** Bruttogehalt 3200 €, Abzüge ca. 35%. Nettogehalt?

$$\text{Netto} = 3200 \times 0,65 = 2080 €$$

### Gehaltserhöhung

**Aufgabe:** Nach 4% Erhöhung: 2496 €. Vorheriges Gehalt?

$$G = \frac{2496}{1,04} = 2400 €$$

## Kreditberechnungen

### Einfacher Ratenkredit

**Aufgabe:** Kredit 12.000 €, 5% p.a., Laufzeit 3 Jahre.

**Zinsen:** $12.000 \times 0,05 \times 3 = 1.800 €$
**Gesamtrückzahlung:** $12.000 + 1.800 = 13.800 €$
**Monatliche Rate:** $13.800 ÷ 36 = 383,33 €$

## Preiskalkulationen

### Handelskalkulation

| Position | Berechnung | Betrag |
|----------|------------|--------|
| Einkaufspreis | | 50,00 € |
| + 40% Aufschlag | 50 × 0,40 | 20,00 € |
| = Nettoverkaufspreis | | 70,00 € |
| + 19% MwSt. | 70 × 0,19 | 13,30 € |
| = Bruttoverkaufspreis | | 83,30 € |
