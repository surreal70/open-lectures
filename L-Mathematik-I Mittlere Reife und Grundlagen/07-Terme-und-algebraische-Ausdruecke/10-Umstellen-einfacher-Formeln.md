# Umstellen einfacher Formeln

> [!info] Lernziele
> - Formeln nach einer Variablen auflösen
> - Die Umkehroperation richtig anwenden
> - Physikalische Formeln umstellen
> - Die Reihenfolge der Umformungen beachten

## Überblick

**Formeln umstellen** bedeutet, eine Gleichung so umzuformen, dass die gewünschte Variable alleine auf einer Seite steht.

## Prinzip

Wende die **Umkehroperation** auf beide Seiten an:

| Operation | Umkehroperation |
|-----------|-----------------|
| + | − |
| − | + |
| · | : |
| : | · |
| ² | √ |
| √ | ² |

## Beispiele

### Aus v = s/t

**Nach s auflösen:**
$$v = \frac{s}{t} \quad|\cdot t$$
$$s = v \cdot t$$

**Nach t auflösen:**
$$v = \frac{s}{t} \quad|\cdot t$$
$$v \cdot t = s \quad|:v$$
$$t = \frac{s}{v}$$

### Aus A = a · b

**Nach a:** $a = \frac{A}{b}$
**Nach b:** $b = \frac{A}{a}$

### Aus A = πr²

**Nach r:**
$$A = \pi r^2 \quad|:\pi$$
$$\frac{A}{\pi} = r^2 \quad|\sqrt{}$$
$$r = \sqrt{\frac{A}{\pi}}$$
