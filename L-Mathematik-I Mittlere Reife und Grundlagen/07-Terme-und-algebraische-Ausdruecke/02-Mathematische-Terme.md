# Mathematische Terme

> [!info] Lernziele
> - Den Aufbau von Termen verstehen
> - Terme aus Texten aufstellen
> - Koeffizienten und Variablen unterscheiden
> - Die Struktur von Termen analysieren

## Überblick

Ein **Term** ist ein sinnvoller mathematischer Ausdruck, der aus Zahlen, Variablen und Rechenzeichen besteht.

## Definition

> [!tip] Definition
> Ein **Term** ist ein mathematischer Ausdruck, der:
> - aus Zahlen, Variablen und Rechenzeichen besteht
> - einen Wert hat (wenn man für Variablen Zahlen einsetzt)
> - keine Gleichheitszeichen enthält

## Bestandteile

```
    ┌─ Koeffizient (Vorzahl)
    │
   3x² + 5x - 7
    │    │    │
    │    │    └─ Konstantes Glied
    │    └─ Term 2. Grades
    └─ Variable mit Exponent
```

### Begriffe

| Begriff | Bedeutung | Beispiel in 3x² + 5x − 7 |
|---------|-----------|--------------------------|
| Koeffizient | Zahl vor der Variablen | 3, 5 |
| Variable | Buchstabe | x |
| Exponent | Hochzahl | 2, 1 |
| Konstante | Zahl ohne Variable | −7 |
| Summand | Durch + oder − getrennt | 3x², 5x, −7 |

## Terme aus Texten

| Text | Term |
|------|------|
| "Das Doppelte von x" | 2x |
| "5 mehr als x" | x + 5 |
| "Die Hälfte von x" | x/2 oder 0,5x |
| "x vermindert um 3" | x − 3 |
| "Das Quadrat von x" | x² |
| "Das Produkt aus a und b" | a · b |

## Arten von Termen

| Art | Beispiel |
|-----|----------|
| Monom | 3x², 5a |
| Binom | x + 2, 3a − b |
| Trinom | x² + 2x + 1 |
| Polynom | allg. Summe von Monomen |
