# Subtraktion von Brüchen

> [!info] **Lernziele**
> Nach diesem Kapitel solltest du:
> - Brüche mit gleichem Nenner subtrahieren können
> - Brüche mit verschiedenen Nennern subtrahieren können
> - Gemischte Zahlen subtrahieren können

---

## Überblick

Die Subtraktion von Brüchen funktioniert analog zur Addition: Bei gleichem Nenner werden die Zähler subtrahiert; bei verschiedenen Nennern muss zuerst ein gemeinsamer Nenner gefunden werden.

Im Alltag begegnet uns die Bruchsubtraktion oft: Wenn von einer $\frac{3}{4}$ vollen Flasche $\frac{1}{4}$ getrunken wird, wie viel bleibt übrig? Oder wenn ein Rezept $\frac{2}{3}$ Tasse Zucker verlangt und du nur $\frac{1}{2}$ Tasse hinzugefügt hast – wie viel fehlt noch?

---

## Gleiche Nenner

$$\frac{a}{c} - \frac{b}{c} = \frac{a - b}{c}$$

**Beispiel:**
$$\frac{5}{7} - \frac{2}{7} = \frac{5 - 2}{7} = \frac{3}{7}$$

> [!note] **Anschauliche Erklärung**
> Wenn du 5 Siebentel hast und 2 Siebentel wegnimmst, bleiben 3 Siebentel übrig. Die Stücke sind gleich groß, also zählst du einfach die Differenz.
>
> ```
> ┌───┬───┬───┬───┬───┬───┬───┐
> │ ▓ │ ▓ │ ▓ │ ▓ │ ▓ │   │   │  =  ⁵⁄₇
> └───┴───┴───┴───┴───┴───┴───┘
>        minus ²⁄₇
>            ↓
> ┌───┬───┬───┬───┬───┬───┬───┐
> │ ▓ │ ▓ │ ▓ │   │   │   │   │  =  ³⁄₇
> └───┴───┴───┴───┴───┴───┴───┘
> ```

## Verschiedene Nenner

1. Hauptnenner bestimmen
2. Brüche erweitern
3. Zähler subtrahieren
4. Ggf. kürzen

**Beispiel:** $\frac{3}{4} - \frac{1}{3}$

$$= \frac{9}{12} - \frac{4}{12} = \frac{5}{12}$$

**Schritt für Schritt:**
1. Hauptnenner: kgV(4, 3) = 12
2. $\frac{3}{4}$ erweitern mit 3: $\frac{9}{12}$
3. $\frac{1}{3}$ erweitern mit 4: $\frac{4}{12}$
4. Subtrahieren: $\frac{9}{12} - \frac{4}{12} = \frac{5}{12}$

> [!tip] **Prüfung durch Addition**
> Du kannst dein Ergebnis prüfen: Ergebnis + Subtrahend = Minuend
> $\frac{5}{12} + \frac{1}{3} = \frac{5}{12} + \frac{4}{12} = \frac{9}{12} = \frac{3}{4}$ ✓

## Gemischte Zahlen subtrahieren

**Beispiel:** $3\frac{1}{4} - 1\frac{2}{3}$

Die sicherste Methode: In unechte Brüche umwandeln:
$$= \frac{13}{4} - \frac{5}{3}$$

Auf Hauptnenner 12:
$$= \frac{39}{12} - \frac{20}{12} = \frac{19}{12} = 1\frac{7}{12}$$

> [!warning] **Häufiger Fehler bei gemischten Zahlen**
> Wenn der Bruchteil des Subtrahenden größer ist als der des Minuenden, darf man NICHT einfach die Bruchteile vertauschen:
>
> **Falsch:** $3\frac{1}{4} - 1\frac{3}{4} = 2\frac{2}{4}$ ✗
>
> **Richtig:** $\frac{13}{4} - \frac{7}{4} = \frac{6}{4} = 1\frac{1}{2}$ ✓

---

## Sonderfall: Negative Ergebnisse

Wenn der Subtrahend größer ist als der Minuend, wird das Ergebnis negativ:

$$\frac{1}{4} - \frac{3}{4} = \frac{1-3}{4} = \frac{-2}{4} = -\frac{1}{2}$$

> [!note] **Negative Brüche**
> Ein negativer Bruch kann auf drei Weisen geschrieben werden:
> $$-\frac{1}{2} = \frac{-1}{2} = \frac{1}{-2}$$
> 
> Alle drei bedeuten dasselbe. Die erste Schreibweise (Minus vor dem Bruch) ist am übersichtlichsten.
