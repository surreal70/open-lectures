# Abkürzungsverzeichnis – Mathematik I

## Mathematische Symbole

### Mengen

| Symbol | Bedeutung |
|--------|-----------|
| $\mathbb{N}$ | Natürliche Zahlen {1, 2, 3, ...} |
| $\mathbb{N}_0$ | Natürliche Zahlen mit Null {0, 1, 2, ...} |
| $\mathbb{Z}$ | Ganze Zahlen {..., -2, -1, 0, 1, 2, ...} |
| $\mathbb{Q}$ | Rationale Zahlen (Brüche) |
| $\mathbb{R}$ | Reelle Zahlen |
| $\emptyset$ | Leere Menge |
| $\in$ | Element von |
| $\notin$ | Nicht Element von |
| $\subset$ | Teilmenge von |
| $\cup$ | Vereinigung |
| $\cap$ | Schnittmenge |

### Operationen

| Symbol | Bedeutung |
|--------|-----------|
| $+$ | Addition (Plus) |
| $-$ | Subtraktion (Minus) |
| $\cdot$ oder $\times$ | Multiplikation (Mal) |
| $:$ oder $\div$ oder $/$ | Division (Geteilt) |
| $=$ | Gleich |
| $\neq$ | Ungleich |
| $<$ | Kleiner als |
| $>$ | Größer als |
| $\leq$ | Kleiner oder gleich |
| $\geq$ | Größer oder gleich |
| $\approx$ | Ungefähr gleich |

| $\sqrt{x}$ | Quadratwurzel von x |
| $\sqrt[n]{x}$ | n-te Wurzel von x |

| $n!$ | n Fakultät |
| $\sum$ | Summe |
| $\prod$ | Produkt |
| $\pi$ | Pi (≈ 3,14159) |
| $\infty$ | Unendlich |
