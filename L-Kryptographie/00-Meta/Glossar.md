# Kryptographie-Glossar

## A

**AEAD (Authenticated Encryption with Associated Data)**
: Verschlüsselungsverfahren, das sowohl Vertraulichkeit als auch Integrität und Authentizität garantiert.

**AES (Advanced Encryption Standard)**
: Symmetrischer Blockverschlüsselungsstandard mit 128-Bit-Blöcken und Schlüssellängen von 128, 192 oder 256 Bit.

**Asymmetrische Kryptographie**
: Kryptographisches Verfahren mit zwei verschiedenen Schlüsseln (öffentlich und privat).

## B

**Blockchiffre**
: Verschlüsselungsalgorithmus, der Daten in festen Blöcken verarbeitet.

## C

**CA (Certificate Authority)**
: Vertrauenswürdige Instanz, die digitale Zertifikate ausstellt.

**CBC (Cipher Block Chaining)**
: Betriebsmodus für Blockchiffren mit Verkettung der Blöcke.

**Chiffretext (Ciphertext)**
: Verschlüsselte Nachricht.

## D

**DES (Data Encryption Standard)**
: Veralteter symmetrischer Verschlüsselungsstandard (56-Bit-Schlüssel).

**Diffie-Hellman**
: Protokoll zum sicheren Schlüsselaustausch über unsichere Kanäle.

## E

**ECC (Elliptic Curve Cryptography)**
: Asymmetrische Kryptographie basierend auf elliptischen Kurven.

**Entropie**
: Maß für die Zufälligkeit/Unvorhersehbarkeit von Daten.

## F

**FIPS (Federal Information Processing Standards)**
: US-amerikanische Kryptographiestandards.

## G

**GCM (Galois/Counter Mode)**
: AEAD-Betriebsmodus für Blockchiffren.

## H

**Hash / Hashfunktion**
: Einwegfunktion, die Eingaben beliebiger Länge auf feste Ausgabelänge abbildet.

**HMAC (Hash-based Message Authentication Code)**
: MAC-Verfahren basierend auf Hashfunktionen.

**HSM (Hardware Security Module)**
: Spezialhardware für sichere Schlüsselspeicherung und kryptographische Operationen.

## I

**Integrität**
: Schutzziel: Daten wurden nicht unbemerkt verändert.

**IV (Initialisierungsvektor)**
: Zufälliger Startwert für Verschlüsselungsoperationen.

## K

**Klartext (Plaintext)**
: Unverschlüsselte Nachricht.

**KDF (Key Derivation Function)**
: Funktion zur Ableitung von Schlüsseln aus einem Master-Schlüssel oder Passwort.

## M

**MAC (Message Authentication Code)**
: Kryptographischer Prüfwert zur Authentifizierung von Nachrichten.

**MitM (Man-in-the-Middle)**
: Angriffsart, bei der ein Angreifer die Kommunikation abfängt und manipuliert.

## N

**Nonce**
: "Number used once" – einmalig verwendeter Wert zur Verhinderung von Replay-Angriffen.

## O

**OAEP (Optimal Asymmetric Encryption Padding)**
: Sicheres Padding-Schema für RSA-Verschlüsselung.

## P

**PFS (Perfect Forward Secrecy)**
: Eigenschaft, dass vergangene Kommunikation auch bei Kompromittierung des Langzeitschlüssels geschützt bleibt.

**PKI (Public Key Infrastructure)**
: Infrastruktur zur Verwaltung von öffentlichen Schlüsseln und Zertifikaten.

**PQC (Post-Quantum Cryptography)**
: Kryptographische Verfahren, die gegen Quantencomputer-Angriffe resistent sind.

## R

**RSA**
: Asymmetrisches Kryptosystem basierend auf dem Faktorisierungsproblem.

## S

**Salt**
: Zufälliger Wert, der Passwörtern vor dem Hashen hinzugefügt wird.

**SHA (Secure Hash Algorithm)**
: Familie kryptographischer Hashfunktionen.

**Symmetrische Kryptographie**
: Kryptographisches Verfahren mit einem gemeinsamen geheimen Schlüssel.

## T

**TLS (Transport Layer Security)**
: Kryptographisches Protokoll zur sicheren Kommunikation über Netzwerke.

**TPM (Trusted Platform Module)**
: Sicherheitschip auf Computern zur Schlüsselspeicherung.

## V

**Vertraulichkeit (Confidentiality)**
: Schutzziel: Nur Berechtigte können Daten lesen.

## X

**X.509**
: Standard für digitale Zertifikate.

## Z

**Zero-Knowledge-Proof**
: Kryptographisches Verfahren zum Beweis von Wissen ohne Preisgabe des Wissens selbst.
