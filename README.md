# Open Lectures

A collection of open educational lecture notes, workbooks, and course materials formatted as Obsidian vaults.

🇩🇪 [Deutsche Version](README.de.md)

## About

This repository contains structured lecture notes for various academic courses. Each course is organized as an independent Obsidian vault, designed for self-study, exam preparation, and knowledge management.

The materials include:
- Comprehensive lecture notes with learning objectives
- Practice exercises with solutions
- Sample exams and exam preparation materials
- Cross-referenced concepts and glossaries

**Language:** The course materials are primarily in **German**. English translations can be provided upon request.

**New to Obsidian?** See the [How-To Guide](HOWTO.md) for installation instructions, a quick reference cheat sheet, and tips for effective studying.
