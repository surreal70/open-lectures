# Open Lectures

Open educational lecture notes and course materials published as Obsidian vaults.

## Purpose

Provide comprehensive, interconnected learning resources that combine:
- Lecture notes with learning objectives
- Practice exercises and sample exams
- Cross-referenced concepts and glossaries
- Visual diagrams and code examples

## Content Language

Course materials are written in **German**. Repository documentation (README, HOWTO) exists in both German and English.

## Licensing

## Audience

- Students for self-study and exam preparation
- Educators as teaching reference
- Anyone interested in the covered topics

## Design Philosophy

- **Networked knowledge**: Wiki-style linking between concepts
- **Visual-first**: Diagrams and illustrations for complex topics
- **Multi-layered**: Progressive depth from overview to details
- **Self-contained**: Each vault works independently in Obsidian
