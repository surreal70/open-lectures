# IEEE 802.11g - WLAN 2.4 GHz (54 Mbit/s)

## Kurzübersicht

**IEEE 802.11g** kombinierte die Reichweite von 802.11b mit der Geschwindigkeit von 802.11a im 2,4-GHz-Band.

| Eigenschaft | Wert |
|-------------|------|
| Veröffentlichung | 2003 |
| Frequenzband | 2,4 GHz (ISM) |
| Max. Datenrate | 54 Mbit/s |
| Modulation | OFDM (+ DSSS für Kompatibilität) |
| Reichweite | ~100 m (indoor) |

## Technische Details

| Parameter | Wert |
|-----------|------|
| Kanalbreite | 20 MHz |
| Anzahl Kanäle | 13 (EU), 3 nicht überlappend |
| Datenraten | 6, 9, 12, 18, 24, 36, 48, 54 Mbit/s |
| Rückwärtskompatibel | Ja (802.11b) |

## Vergleich

| Aspekt | 802.11b | 802.11g | 802.11a |
|--------|---------|---------|---------|
| Frequenz | 2,4 GHz | 2,4 GHz | 5 GHz |
| Max. Rate | 11 Mbit/s | 54 Mbit/s | 54 Mbit/s |
| Modulation | DSSS | OFDM | OFDM |
| Kompatibel | - | 802.11b | - |
