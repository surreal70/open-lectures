# BS2000 (BS2000/OSD)

## Überblick

| Eigenschaft | Wert |
|-------------|------|
| **Typ** | Mainframe-Betriebssystem |
| **Entwickler** | Fujitsu Technology Solutions (früher Siemens) |
| **Erstveröffentlichung** | 1975 |
| **Aktuelle Version** | BS2000/OSD V12 |
| **Lizenz** | Proprietär |
| **Architektur** | Fujitsu BS2000-Mainframes |

## Zusammenfassung

BS2000 ist ein europäisches Mainframe-Betriebssystem, ursprünglich von Siemens entwickelt. Es wird hauptsächlich in Deutschland und Europa für Großrechner-Anwendungen in Behörden und großen Unternehmen eingesetzt.

### Einsatzgebiete

| Branche | Anwendungen |
|---------|-------------|
| Öffentlicher Dienst | Verwaltungssysteme |
| Banken | Kernbankensysteme |
| Versicherungen | Bestandsführung |
| Industrie | ERP-Systeme |

### Hauptmerkmale

| Feature | Beschreibung |
|---------|--------------|
| **POSIX** | Unix-Kompatibilitätsschicht |
| **SDF** | Dialogschnittstelle |
| **DAB** | Disk Access Block |
| **openSEAS** | Java/Web-Integration |
| **VM2000** | Virtualisierung |

### Architektur

```
BS2000/OSD Schichten
┌─────────────────────────────────────────┐
│    openSEAS / POSIX Anwendungen         │
├─────────────────────────────────────────┤
│    Subsysteme (SESAM, UDS, UTM)         │
├─────────────────────────────────────────┤
│           BS2000 Kernel                 │
├─────────────────────────────────────────┤
│    VM2000 Hypervisor (optional)         │
├─────────────────────────────────────────┤
│    Fujitsu Hardware / SX-Server         │
└─────────────────────────────────────────┘
```

### Wichtige Subsysteme

- **SESAM/SQL**: Relationale Datenbank
- **UDS/SQL**: Netzwerk-Datenbank
- **UTM**: Transaktionsmonitor
- **openFT**: Dateitransfer
- **OMNIS**: Netzwerkmanagement

### BS2000 auf x86

Mit "BS2000/OSD on Linux" kann BS2000 als Gastsystem auf Linux-Servern laufen, was die Migration auf Standard-Hardware ermöglicht.
