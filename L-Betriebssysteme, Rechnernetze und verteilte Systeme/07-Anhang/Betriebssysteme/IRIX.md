# IRIX

## Überblick

| Eigenschaft | Wert |
|-------------|------|
| **Typ** | Unix-Betriebssystem |
| **Entwickler** | Silicon Graphics (SGI) |
| **Erstveröffentlichung** | 1988 |
| **Letzte Version** | 6.5.30 (2006) |
| **Lizenz** | Proprietär |
| **Architektur** | MIPS |

## Zusammenfassung

IRIX war das Unix-Betriebssystem von Silicon Graphics für ihre Grafik-Workstations und Supercomputer. Es war führend in Echtzeit-Grafik, Multimedia und wissenschaftlichem Rechnen.

### Einsatzgebiete

| Bereich | Anwendungen |
|---------|-------------|
| Film/VFX | Jurassic Park, Toy Story |
| 3D/CAD | Alias, SoftImage, Maya |
| Wissenschaft | Visualisierung, Simulation |
| Medizin | 3D-Bildgebung |

### Technische Besonderheiten

- **XFS**: Hochperformantes 64-bit Dateisystem
- **REACT**: Echtzeit-Erweiterungen
- **OpenGL**: Native Hardware-Beschleunigung
- **NUMA**: Non-Uniform Memory Access
- **InfiniteReality**: Grafik-Pipeline

### Versionsgeschichte

| Version | Jahr | Basis |
|---------|------|-------|
| IRIX 3.x | 1988 | System V R3 |
| IRIX 4.x | 1991 | System V R3.2 |
| IRIX 5.x | 1993 | System V R4 |
| IRIX 6.x | 1994 | 64-bit, XFS |
| IRIX 6.5 | 1998 | Letzte Hauptversion |

### Ende

Mit dem Niedergang von SGI (Übergang zu Linux und Intel-Hardware) wurde IRIX 2006 eingestellt. Das XFS-Dateisystem lebt in Linux weiter.
