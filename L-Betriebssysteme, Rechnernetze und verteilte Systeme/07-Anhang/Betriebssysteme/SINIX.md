# SINIX / Reliant UNIX

## Überblick

| Eigenschaft | Wert |
|-------------|------|
| **Typ** | Unix-Betriebssystem |
| **Entwickler** | Siemens AG |
| **Erstveröffentlichung** | 1984 |
| **Letzte Version** | Reliant UNIX 5.45 (2001) |
| **Lizenz** | Proprietär |
| **Basis** | System V |

## Zusammenfassung

SINIX war Siemens' Unix-Implementierung für ihre RM- und MX-Rechnerfamilien. Als System V Release 4 erschien, wurde SINIX zu "Reliant UNIX" umbenannt und erhielt Hochverfügbarkeits-Features für den Enterprise-Einsatz.

### Einsatzgebiete

- Siemens RM-Workstations
- MX-300/500 Server
- Enterprise-Datenbanksysteme
- Telekommunikationsinfrastruktur

### Technische Merkmale

| Feature | Beschreibung |
|---------|--------------|
| **HA-Cluster** | Hochverfügbarkeit mit Failover |
| **MIPS/Intel** | Multi-Architektur-Support |
| **SAP-zertifiziert** | Frühe SAP R/3-Plattform |
| **CFS** | Cluster File System |

### SINIX-Versionen

| Version | Basis | Jahr |
|---------|-------|------|
| SINIX V1 | System V R2 | 1984 |
| SINIX V5.2 | System V R3.2 | 1987 |
| SINIX V5.4 | System V R4 | 1990 |
| Reliant UNIX | SVR4.2MP | 1995 |

### Ende

Mit dem Rückzug von Siemens aus dem Unix-Hardware-Geschäft (Übernahme durch Fujitsu Siemens) wurde SINIX/Reliant UNIX 2001 eingestellt. Bestehende Installationen migrierten zu Solaris oder Linux.
