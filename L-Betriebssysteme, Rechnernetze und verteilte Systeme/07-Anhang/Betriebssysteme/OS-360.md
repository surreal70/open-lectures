# OS/360

## Überblick

| Eigenschaft | Wert |
|-------------|------|
| **Typ** | Mainframe-Betriebssystem |
| **Entwickler** | IBM |
| **Erstveröffentlichung** | 1966 |
| **Lizenz** | Proprietär |
| **Architektur** | IBM System/360, System/370 |

## Zusammenfassung

OS/360 war eines der bedeutendsten Betriebssysteme der Computergeschichte. Es war das erste Betriebssystem, das eine gesamte Produktlinie mit unterschiedlicher Hardware abdeckte, und Vorläufer aller modernen IBM-Mainframe-Systeme.

### Historische Bedeutung

- Erstes OS für eine komplette Hardwarefamilie
- Revolutionäres (und chaotisches) Software-Projekt
- Fred Brooks' "Mythical Man-Month" basiert auf OS/360-Erfahrungen
- Begründete das Konzept der Aufwärtskompatibilität

### Varianten

| Variante | Beschreibung |
|----------|--------------|
| **PCP** | Primary Control Program (Stapelverarbeitung) |
| **MFT** | Multiprogramming with Fixed number of Tasks |
| **MVT** | Multiprogramming with Variable number of Tasks |
| **SVS** | Single Virtual Storage |
| **MVS** | Multiple Virtual Systems (Nachfolger) |

### Innovations

| Innovation | Beschreibung |
|------------|--------------|
| **JCL** | Job Control Language |
| **Cataloged Datasets** | Dateiverwaltung |
| **Spooling** | SPOOL-Konzept |
| **Multiprogramming** | Mehrere Jobs gleichzeitig |


### Das "Tar Pit"-Projekt

Fred Brooks beschrieb OS/360 als eines der komplexesten Software-Projekte seiner Zeit:
- 1000+ Programmierer
- 5000+ Personenjahre
- Millionen Zeilen Code
- Massive Verzögerungen und Kostenüberschreitungen
