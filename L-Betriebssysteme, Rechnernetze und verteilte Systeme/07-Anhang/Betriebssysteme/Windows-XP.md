# Windows XP

## Überblick

| Eigenschaft | Wert |
|-------------|------|
| **Typ** | 32/64-bit NT-Betriebssystem |
| **Entwickler** | Microsoft |
| **Erstveröffentlichung** | 25. Oktober 2001 |
| **Support-Ende** | 8. April 2014 |
| **Lizenz** | Proprietär |
| **Codename** | Whistler |
| **Kernel** | NT 5.1 |

## Zusammenfassung

Windows XP vereinte erstmals die Consumer- und Enterprise-Linien auf NT-Basis. Mit seiner langen Lebensdauer (12+ Jahre) und großer Verbreitung gilt es als eines der erfolgreichsten Betriebssysteme der Geschichte.

### Editionen

| Edition | Zielgruppe |
|---------|------------|
| **Home** | Heimanwender |
| **Professional** | Business |
| **Media Center** | Entertainment |
| **Tablet PC** | Stiftbedienung |
| **x64** | 64-bit (2005) |
| **Embedded** | Industrie, POS |

### Langlebigkeit

Windows XP blieb weit über sein Support-Ende hinaus im Einsatz:
- Geldautomaten
- Industriesteuerungen
- Point-of-Sale-Systeme
- Medizingeräte

### Sicherheitsprobleme

Besonders in den ersten Jahren war XP anfällig:
- Blaster-Wurm (2003)
- Sasser-Wurm (2004)
- SP2 brachte grundlegende Verbesserungen
