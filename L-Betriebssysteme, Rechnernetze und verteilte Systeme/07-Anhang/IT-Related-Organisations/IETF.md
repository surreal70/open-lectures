# 13010 IETF - Internet Engineering Task Force

## Überblick

Die Internet Engineering Task Force (IETF) ist eine offene Standardisierungsorganisation, die freiwillige Internet-Standards entwickelt und fördert, insbesondere die technischen Standards, die das Internet-Protokollpaket (TCP/IP) umfassen.

## Zweck

- Entwickelt Internet-Standards durch offene Prozesse
- Veröffentlicht Request for Comments (RFC) Dokumente
- Definiert Protokolle für Internet-Kommunikation
- Pflegt und entwickelt grundlegende Internet-Infrastrukturstandards weiter

## Wichtige Ergebnisse

| Ergebnis | Beschreibung |
|----------|--------------|
| **RFCs** | Technische Spezifikationen für Internet-Protokolle |
| **Internet-Standards** | Protokolle, die zu Internet-Standards werden |
| **Best Current Practices** | Betriebsrichtlinien |
| **Informational Documents** | Allgemeine Informationen |

## Wichtige entwickelte Standards

- TCP/IP (RFC 791, RFC 793)
- HTTP (RFC 9110)
- TLS (RFC 8446)
- DNS (RFC 1035)
- SMTP (RFC 5321)
- IPv6 (RFC 8200)
- DHCP (RFC 2131)
- NTP (RFC 5905)
