# 13050 FSF - Free Software Foundation

## Überblick

Die Free Software Foundation (FSF) ist eine gemeinnützige Organisation, die von Richard Stallman gegründet wurde, um die Freiheit der Computernutzer zu fördern. Die FSF pflegt die Definition Freier Software und entwickelt die GNU General Public License (GPL).

## Zweck

- Fördert die Freie-Software-Bewegung
- Entwickelt und pflegt Freie-Software-Lizenzen (GPL, LGPL, AGPL)
- Unterstützt das GNU-Projekt
- Setzt sich für Softwarefreiheit ein

## Die vier Freiheiten

Freie Software muss diese Freiheiten bieten:

| Freiheit | Beschreibung |
|---------|-------------|
| **Freiheit 0** | Das Programm für jeden Zweck ausführen |
| **Freiheit 1** | Den Quellcode studieren und modifizieren |
| **Freiheit 2** | Kopien weiterverbreiten |
| **Freiheit 3** | Modifizierte Versionen verbreiten |

## Wichtige Lizenzen

| Lizenz | Typ | Beschreibung |
|---------|------|-------------|
| **GPL v3** | Starkes Copyleft | Ableitungen müssen GPL sein |
| **LGPL v3** | Schwaches Copyleft | Kann mit proprietärer Software gelinkt werden |
| **AGPL v3** | Netzwerk-Copyleft | Beinhaltet Netzwerknutzung |
| **FDL** | Dokumentation | Für Handbücher/Dokumentation |

## GNU-Projekt

Die FSF sponsert das GNU-Projekt, das bereitstellt:
- GNU/Linux-Betriebssystemkomponenten
- GCC (GNU Compiler Collection)
- GNU Core Utilities
- Bash-Shell
- GNOME-Desktop
