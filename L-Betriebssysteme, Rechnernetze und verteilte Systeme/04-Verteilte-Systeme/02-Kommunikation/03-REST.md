# REST

## Definition

Representational State Transfer (REST) ist ein Architekturstil für verteilte Hypermedia-Systeme, der auf zustandslosen HTTP-Operationen basiert.

## Erklärung

REST nutzt HTTP-Methoden (GET, POST, PUT, DELETE) für CRUD-Operationen auf Ressourcen. Es ist zustandslos, d.h. jede Anfrage enthält alle notwendigen Informationen. RESTful APIs sind weit verbreitet für Web-Services und Microservices.

## Eigenschaften

- Ressourcenorientierung (URIs identifizieren Ressourcen)
- Zustandslosigkeit (Stateless)
- Einheitliche Schnittstelle (Uniform Interface)
- Client-Server-Architektur
- Cachefähigkeit
- Layered System möglich

## Beispiele

- GitHub REST API
- Twitter API
- Kubernetes API Server
