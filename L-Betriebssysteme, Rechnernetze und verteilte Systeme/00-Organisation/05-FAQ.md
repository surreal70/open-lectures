### Wo finde ich die Vorlesungsmaterialien?

Die Materialien sind in diesem Obsidian Vault organisiert:
- [[00-BS-Index|Betriebssysteme]]
- [[00-RN-Index|Rechnernetze]]
- [[00-VS-Index|Verteilte Systeme]]

Der Vault kann von GutHub bezogen werden:

    **https://github.com/surreal70/open-lectures**

downloaden sie das Github repository als zipfile oder clonen Sie das Repo auf ihren lokalen PC (bevorzugt , nützlich für Updates und Aktualisierungen),

    git clone https://github.com/surreal70/open-lectures.git

Der Vault für diese Vorlesung ist unter 

        **Betriebsysteme, Rechnernetze und verteilte Systeme** 

finden.
