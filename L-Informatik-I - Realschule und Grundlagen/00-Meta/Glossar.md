# Glossar - Informatik I

## A

**Algorithmus**
Eine endliche Folge von eindeutigen Anweisungen zur Lösung eines Problems.

**ASCII**
American Standard Code for Information Interchange – 7-Bit-Zeichencodierung.

**Arbeitsspeicher (RAM)**
Random Access Memory – flüchtiger Speicher für laufende Programme und Daten.

## B

**Betriebssystem**
Software, die Hardware verwaltet und Schnittstelle zwischen Anwendungen und Hardware bildet.

**Binärsystem**
Zahlensystem zur Basis 2 mit den Ziffern 0 und 1.

**Bit**
Kleinste Informationseinheit – 0 oder 1.

**Byte**
8 Bits – grundlegende Speichereinheit.

## C

**Client**
Rechner oder Programm, das Dienste von einem Server anfordert.

**CPU**
Central Processing Unit – Prozessor, führt Berechnungen aus.

**CSS**
Cascading Style Sheets – Sprache zur Gestaltung von Webseiten.

## D

**Daten**
Rohe, unverarbeitete Fakten (Zahlen, Zeichen, Symbole).

**Datenbank**
Strukturierte Sammlung von Daten mit Zugriffsmöglichkeiten.

**Datentyp**
Klassifikation von Daten (Integer, String, Boolean, etc.).

**DNS**
Domain Name System – übersetzt Domainnamen in IP-Adressen.

## E-F

**Firewall**
Sicherheitssystem zum Schutz von Netzwerken.

**Funktion**
Wiederverwendbarer Codeblock mit definierter Aufgabe.

## G-H

**Hardware**
Physische Komponenten eines Computers.

**Hexadezimalsystem**
Zahlensystem zur Basis 16 (0-9, A-F).

**HTML**
HyperText Markup Language – Auszeichnungssprache für Webseiten.

**HTTP/HTTPS**
HyperText Transfer Protocol – Protokoll für Webkommunikation (S = Secure).

## I-J

**Information**
Verarbeitete, bedeutungsvolle Daten.

**Informatik**
Wissenschaft von der systematischen Verarbeitung von Informationen.

**Internet**
Weltweites Netzwerk von Computernetzwerken.

**IP-Adresse**
Eindeutige Adresse eines Geräts im Netzwerk.

## K-L

**KI (Künstliche Intelligenz)**
Maschinelle Systeme, die intelligentes Verhalten zeigen.

**Komprimierung**
Verringerung der Datenmenge bei Speicherung oder Übertragung.

**LAN**
Local Area Network – lokales Netzwerk.

## M-N

**Netzwerk**
Verbund von Computern zum Datenaustausch.

## O-P

**Programm**
Folge von Anweisungen, die ein Computer ausführt.

**Programmiersprache**
Formale Sprache zur Formulierung von Programmen.

**Prozessor**
Siehe CPU.

**Python**
Höhere Programmiersprache, einfach zu lernen.

## Q-R

**RAM**
Siehe Arbeitsspeicher.

**Router**
Netzwerkgerät zur Weiterleitung von Datenpaketen.

## S

**Server**
Rechner oder Programm, das Dienste für Clients bereitstellt.

**Software**
Programme und Daten, die auf Hardware laufen.

**SQL**
Structured Query Language – Sprache für Datenbankabfragen.

**SSD**
Solid State Drive – Festspeicher ohne bewegliche Teile.

## T-U

**Unicode**
Internationaler Standard zur Codierung von Schriftzeichen.

**URL**
Uniform Resource Locator – Webadresse.

**UTF-8**
Variable-Länge Unicode-Codierung.

## V-W

**Variable**
Benannter Speicherplatz für Daten in einem Programm.

**Virus**
Schadsoftware, die sich selbst verbreitet.

**WLAN**
Wireless Local Area Network – drahtloses lokales Netzwerk.

**WWW**
World Wide Web – Hypertext-System im Internet.
