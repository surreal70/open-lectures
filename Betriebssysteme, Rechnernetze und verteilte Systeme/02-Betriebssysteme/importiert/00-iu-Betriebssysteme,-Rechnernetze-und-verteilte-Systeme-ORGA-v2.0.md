Voraussetzungen, Tools, et al
Für die Bearbeitung einiger Aufgaben benötigen Sie einige Werkzeuge für den
praktischen Teil.
 Einen Hypervisor (Virtualisierungssoftware) – welche Sie verwenden ist Ihnen
überlassen:
- VMWare Workstation, VirtualBox, ProxMox oder Alternative für MacOS
 Folgende virtuellen Maschinen werden für unser Lab in diesem Hypervisor
benötigt:
- Ubuntu 26.04 (https://ubuntu.com/), Server  – Netzwerk bridge-mode
- Ein Windows Desktop, alternativ Linux Desktop – Netzwerk bridge-mode
(https://www.microsoft.com/de-de/software-download/windows10ISO )
 Weiterhin  sollten Sie sich mit folgenden Werkzeugen vertraut machen:
- Wireshark (https://www.wireshark.org/ )
- Nmap (https://nmap.org )
- Traceroute und ping (Bestandteil von jedem Betriebssystem)
- netstat (Bestandteil von jedem Betriebssystem)
- route (Bestandteil von jedem Betriebssystem)
