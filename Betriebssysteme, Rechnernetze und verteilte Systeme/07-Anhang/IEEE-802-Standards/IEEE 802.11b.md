# IEEE 802.11b - WLAN 2.4 GHz

## Kurzübersicht

**IEEE 802.11b** war der erste weit verbreitete Wi-Fi-Standard und ermöglichte den Durchbruch von WLAN im Consumer-Bereich.

| Eigenschaft | Wert |
|-------------|------|
| Veröffentlichung | 1999 |
| Frequenzband | 2,4 GHz (ISM) |
| Max. Datenrate | 11 Mbit/s |
| Modulation | DSSS/CCK |
| Reichweite | ~100 m (indoor) |

## Technische Details

| Parameter | Wert |
|-----------|------|
| Kanalbreite | 22 MHz |
| Anzahl Kanäle | 13 (EU), 3 nicht überlappend |
| Datenraten | 1, 2, 5.5, 11 Mbit/s |
