# PCI SSC - Payment Card Industry Security Standards Council

## Überblick

Das **Payment Card Industry Security Standards Council (PCI SSC)** ist ein globales Forum, das Zahlungskartensicherheitsstandards entwickelt, verwaltet und fördert. 2006 von American Express, Discover, JCB International, MasterCard und Visa Inc. gegründet, verwaltet das PCI SSC die Sicherheitsstandards für Organisationen, die Kreditkartendaten verarbeiten.

## Zweck

- Entwicklung und Pflege des PCI Data Security Standard (PCI DSS)
- Verwaltung von Validierungs- und Bewertungsprogrammen
- Qualifizierung von Sicherheitsprüfern und Anbietern
- Sensibilisierung für Zahlungssicherheit
- Bereitstellung von Leitfäden und unterstützenden Ressourcen

## Wichtige Standards

### PCI DSS (Data Security Standard)
- 12 Anforderungen zum Schutz von Karteninhaberdaten
- Netzwerksicherheit, Zugangskontrolle, Überwachung
- Aktuelle Version: PCI DSS v4.0
- Gilt für alle Unternehmen, die Zahlungskartendaten verarbeiten

### Unterstützende Standards
- **PCI PA-DSS**: Payment Application Data Security Standard
- **PCI PTS**: PIN Transaction Security (Terminals)
- **PCI P2PE**: Point-to-Point Encryption
- **PCI 3DS**: 3-D Secure für E-Commerce
- **PCI SSF**: Software Security Framework (ersetzt PA-DSS)
- **PCI Card Production**: Kartenherstellungssicherheit

### Programme
- QSA (Qualified Security Assessor)-Programm
- ASV (Approved Scanning Vendor)-Programm
- PA-QSA (Payment Application QSA)-Programm
- PCI Forensic Investigator (PFI)-Programm

## Relevanz für den IT-Betrieb

PCI SSC betrifft:
- **E-Commerce-Systeme**: Absicherung der Zahlungsverarbeitung
- **Netzwerksicherheit**: Segmentierung, Firewall-Anforderungen
- **Zugangskontrolle**: Authentifizierungs- und Protokollierungsanforderungen
- **Schwachstellenmanagement**: Scanning- und Patching-Anforderungen
