# 13036 CIS - Center for Internet Security

## Überblick

Das Center for Internet Security (CIS) ist eine gemeinnützige Organisation, die sich auf die Verbesserung der Cybersicherheitsbereitschaft und -reaktion konzentriert. CIS ist am besten bekannt für die CIS Controls und CIS Benchmarks, die praktische Sicherheitsanleitungen bieten.

## Zweck

- Entwickelt Security Best Practices (CIS Controls)
- Veröffentlicht Konfigurationsbenchmarks (CIS Benchmarks)
- Betreibt MS-ISAC und EI-ISAC für Regierungen
- Stellt Sicherheitstools und Ressourcen bereit

## Wichtige Produkte

### CIS Controls

Die CIS Critical Security Controls (ehemals SANS Top 20) sind priorisierte Maßnahmen zum Schutz vor Cyberangriffen:

| Control | Name |
|---------|------|
| 1 | Inventarisierung und Kontrolle von Unternehmens-Assets |
| 2 | Inventarisierung und Kontrolle von Software-Assets |
| 3 | Datenschutz |
| 4 | Sichere Konfiguration von Unternehmens-Assets und Software |
| 5 | Kontoverwaltung |
| 6 | Zugriffskontrollverwaltung |
| 7 | Kontinuierliches Schwachstellenmanagement |
| 8 | Audit-Log-Management |
| 9 | E-Mail- und Webbrowser-Schutz |
| 10 | Malware-Abwehr |
| 11 | Datenwiederherstellung |
| 12 | Netzwerkinfrastruktur-Management |
| 13 | Netzwerküberwachung und -verteidigung |
| 14 | Sicherheitsbewusstsein und Kompetenztraining |
| 15 | Dienstleister-Management |
| 16 | Anwendungssoftware-Sicherheit |
| 17 | Incident-Response-Management |
| 18 | Penetration Testing |

### CIS Benchmarks

Sichere Konfigurationsleitfäden für verschiedene Plattformen:

| Kategorie | Beispiele |
|----------|----------|
| **Betriebssysteme** | Windows, Linux, macOS |
| **Cloud-Anbieter** | AWS, Azure, GCP |
| **Container** | Docker, Kubernetes |
| **Netzwerkgeräte** | Cisco, Palo Alto |
| **Datenbanken** | MySQL, PostgreSQL, MSSQL |
| **Webserver** | Apache, Nginx, IIS |

### Implementation Groups (IGs)

| IG | Zielgruppe | Controls |
|----|--------|----------|
| IG1 | Kleine Organisationen | Basis-Controls |
| IG2 | Mittlere Organisationen | IG1 + zusätzliche |
| IG3 | Große/sensible | Alle Controls |
