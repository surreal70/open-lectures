# OASIS - Organization for the Advancement of Structured Information Standards

## Überblick

**OASIS** ist ein gemeinnütziges Konsortium, das die Entwicklung, Konvergenz und Übernahme offener Standards für die globale Informationsgesellschaft vorantreibt. 1993 gegründet (ursprünglich SGML Open), ist OASIS zu einer der einflussreichsten Standardisierungsorganisationen für Enterprise IT, Cloud Computing, Cybersicherheit und IoT geworden.

## Zweck

- Entwicklung offener Standards für Sicherheit, Cloud, IoT und Enterprise-Anwendungen
- Bereitstellung eines herstellerneutralen Forums für branchenweite Zusammenarbeit
- Überbrückung der Lücke zwischen Innovation und Standardisierung
- Förderung der Interoperabilität durch offene Spezifikationen

## Wichtige Ergebnisse

### Sicherheitsstandards
- **STIX/TAXII**: Structured Threat Information Expression / Trusted Automated Exchange
- **SAML**: Security Assertion Markup Language (SSO)
- **KMIP**: Key Management Interoperability Protocol
- **OpenC2**: Open Command and Control

### Enterprise-Standards
- **AMQP**: Advanced Message Queuing Protocol
- **MQTT**: Message Queuing Telemetry Transport (IoT)
- **OData**: Open Data Protocol
- **TOSCA**: Topology and Orchestration Specification for Cloud Applications

### Dokumentstandards
- **ODF**: Open Document Format
- **DocBook**: Technische Dokumentations-Markup

## Relevanz für IT-Betrieb

OASIS-Standards sind kritisch für:
- **Threat Intelligence Sharing**: STIX/TAXII für Sicherheitsbetrieb
- **Identity Federation**: SAML für Enterprise SSO
- **Message Queuing**: AMQP/MQTT für verteilte Systeme
- **Cloud-Orchestrierung**: TOSCA für Infrastructure as Code
