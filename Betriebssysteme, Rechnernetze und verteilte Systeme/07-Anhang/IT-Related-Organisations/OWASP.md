# 13037 OWASP - Open Web Application Security Project

## Überblick

Das Open Worldwide Application Security Project (OWASP) ist eine gemeinnützige Stiftung, die sich für die Verbesserung der Softwaresicherheit einsetzt. OWASP ist bekannt für seine Community-geführten Open-Source-Projekte, einschließlich der berühmten OWASP Top 10.

## Zweck

- Verbessert die Anwendungssicherheit durch Open-Source-Projekte
- Stellt kostenlose Sicherheitstools und Ressourcen bereit
- Entwickelt Sicherheitstest-Methodologien
- Schult Entwickler in sicherer Programmierung

## Wichtige Projekte

### OWASP Top 10 (2021)

Die kritischsten Sicherheitsrisiken für Webanwendungen:

| Rang | Risiko |
|------|------|
| A01 | Broken Access Control |
| A02 | Cryptographic Failures |
| A03 | Injection |
| A04 | Insecure Design |
| A05 | Security Misconfiguration |
| A06 | Vulnerable and Outdated Components |
| A07 | Identification and Authentication Failures |
| A08 | Software and Data Integrity Failures |
| A09 | Security Logging and Monitoring Failures |
| A10 | Server-Side Request Forgery (SSRF) |
