# 13051 OSI - Open Source Initiative

## Überblick

Die Open Source Initiative (OSI) ist eine gemeinnützige Organisation, die sich der Förderung und dem Schutz von Open-Source-Software widmet. Die OSI pflegt die Open Source Definition und genehmigt Lizenzen als "OSI Approved".

## Zweck

- Pflegt die Open Source Definition (OSD)
- Genehmigt Open-Source-Lizenzen
- Setzt sich für Open-Source-Software ein
- Schult über Open-Source-Lizenzierung

## Open Source Definition (OSD)

Die 10 Kriterien für Open-Source-Software:

| Kriterium | Beschreibung |
|-----------|-------------|
| 1 | Freie Weiterverbreitung |
| 2 | Verfügbarkeit des Quellcodes |
| 3 | Abgeleitete Werke erlaubt |
| 4 | Integrität des Quellcodes des Autors |
| 5 | Keine Diskriminierung von Personen oder Gruppen |
| 6 | Keine Diskriminierung von Anwendungsbereichen |
| 7 | Verteilung der Lizenz |
| 8 | Lizenz darf nicht produktspezifisch sein |
| 9 | Lizenz darf andere Software nicht einschränken |
| 10 | Lizenz muss technologieneutral sein |

## OSI-genehmigte Lizenzen

| Kategorie | Beispiele |
|----------|----------|
| **Permissiv** | MIT, Apache 2.0, BSD |
| **Copyleft** | GPL, AGPL, LGPL |
| **Schwaches Copyleft** | MPL, EPL, CDDL |
| **Public Domain** | CC0, Unlicense |

### Beliebte Lizenzen

| Lizenz | Typ | Bekannte Verwendungen |
|---------|------|--------------|
| **MIT** | Permissiv | Node.js, React, jQuery |
| **Apache 2.0** | Permissiv | Android, Kubernetes, Spark |
| **GPL v3** | Copyleft | Linux, WordPress, Bash |
| **BSD 3-Clause** | Permissiv | FreeBSD, PostgreSQL |
| **MPL 2.0** | Schwaches Copyleft | Firefox, Thunderbird |
