# 13054 CNCF - Cloud Native Computing Foundation

## Überblick

Die Cloud Native Computing Foundation (CNCF) ist ein Linux-Foundation-Projekt, das Cloud-Native-Open-Source-Projekte hostet und fördert, darunter Kubernetes, Prometheus und viele andere.

## Zweck

- Hostet Cloud-Native-Projekte
- Fördert das Cloud-Native-Ökosystem
- Bietet Governance für Projekte
- Definiert Cloud Native Computing

## Projektreifegrade

| Stufe | Beschreibung | Beispiele |
|-------|-------------|----------|
| **Graduated** | Produktionsreif, weit verbreitet | Kubernetes, Prometheus, Envoy |
| **Incubating** | Wachsende Verbreitung, reifend | Argo, Cilium, Flux |
| **Sandbox** | Frühes Stadium, experimentell | Verschiedene neue Projekte |

## Wichtige Graduated-Projekte

| Projekt | Zweck |
|---------|---------|
| **Kubernetes** | Container-Orchestrierung |
| **Prometheus** | Monitoring und Alerting |
| **Envoy** | Service Proxy |
| **CoreDNS** | DNS-Server |
| **containerd** | Container Runtime |
| **Helm** | Paketmanager |
| **etcd** | Verteilter Key-Value Store |
| **Fluentd** | Log Collector |
| **Harbor** | Container Registry |
| **Jaeger** | Distributed Tracing |
| **Linkerd** | Service Mesh |
| **Open Policy Agent** | Policy Engine |
| **Vitess** | Datenbank-Clustering |
