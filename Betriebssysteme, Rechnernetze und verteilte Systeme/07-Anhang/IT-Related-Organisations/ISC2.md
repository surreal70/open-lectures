# 13040 ISC2 - International Information System Security Certification Consortium

## Überblick

ISC2 (International Information System Security Certification Consortium) ist eine gemeinnützige Organisation, die auf Informationssicherheitsausbildung und -zertifizierungen spezialisiert ist. ISC2 ist vor allem für die CISSP-Zertifizierung bekannt, eine der anerkanntesten Qualifikationen in der Cybersicherheit.

## Zweck

- Bietet Cybersicherheitszertifizierungen an
- Entwickelt Sicherheitsausbildungsprogramme
- Pflegt einen professionellen Ethikkodex
- Fördert den Berufsstand der Informationssicherheit

## Zertifizierungen

| Zertifizierung | Name | Fokus |
|---------------|------|-------|
| **CISSP** | Certified Information Systems Security Professional | Senior Security Professionals |
| **SSCP** | Systems Security Certified Practitioner | Praktische Sicherheit |
| **CCSP** | Certified Cloud Security Professional | Cloud-Sicherheit |
| **CSSLP** | Certified Secure Software Lifecycle Professional | Sichere Entwicklung |
| **CGRC** | Governance, Risk and Compliance | GRC-Fachleute |
| **ISSAP** | Information Systems Security Architecture Professional | CISSP-Spezialisierung |
| **ISSEP** | Information Systems Security Engineering Professional | CISSP-Spezialisierung |
| **ISSMP** | Information Systems Security Management Professional | CISSP-Spezialisierung |
