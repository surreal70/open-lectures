# 13020 IANA - Internet Assigned Numbers Authority

## Überblick

Die Internet Assigned Numbers Authority (IANA) ist für die globale Koordination von DNS-Root, IP-Adressierung und anderen Internet-Protokoll-Ressourcen verantwortlich. IANA ist eine von ICANN betriebene Funktion.

## Zweck

- Koordiniert globale IP-Adresszuteilung
- Verwaltet DNS-Root-Zone
- Pflegt Protokollparameter-Register
- Weist Autonomous System Numbers (ASN) zu

## Hauptverantwortlichkeiten

| Funktion | Beschreibung |
|----------|--------------|
| **IP-Adresszuteilung** | Verteilt IP-Blöcke an Regional Internet Registries |
| **DNS-Root-Verwaltung** | Pflegt die Root-Zone-Datenbank |
| **Protokollparameter** | Registriert Portnummern, Protokollnummern |
| **TLD-Delegation** | Verwaltet Top-Level-Domain-Zuweisungen |
| **Special-Use Domains** | Reserviert Domains wie .localhost, .example |

## IANA-Register

| Register | Beispiele |
|----------|-----------|
| **Portnummern** | 22 (SSH), 80 (HTTP), 443 (HTTPS) |
| **Protokollnummern** | 6 (TCP), 17 (UDP), 1 (ICMP) |
| **Adressraum** | IPv4, IPv6-Zuteilungen |
| **AS-Nummern** | BGP Autonomous System Numbers |
| **Medientypen** | application/json, text/html |
| **URI-Schemata** | http, https, mailto, tel |

## Special-Purpose-Adressblöcke

- 10.0.0.0/8 (Privat)
- 172.16.0.0/12 (Privat)
- 192.168.0.0/16 (Privat)
- 127.0.0.0/8 (Loopback)
