# Minix

## Kurzinfo

| Eigenschaft | Wert |
|-------------|------|
| **Typ** | Mikrokernel |
| **Erstveröffentlichung** | 1987 |
| **Entwickler** | Andrew S. Tanenbaum |
| **Lizenz** | BSD (ab Minix 3) |
| **Aktuell** | Minix 3 |

## Beschreibung

Minix wurde von Andrew Tanenbaum als Lehrbetriebssystem für sein Buch "Operating Systems: Design and Implementation" entwickelt. Es inspirierte Linus Torvalds zur Entwicklung von Linux (1991).

Minix 3 ist ein vollständiges Mikrokernel-OS mit Fokus auf Zuverlässigkeit. Interessanterweise läuft Minix heute auf Milliarden von Geräten - in der Intel Management Engine (ME) moderner CPUs.
