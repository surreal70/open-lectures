# Windows 1.0

## Überblick

| Eigenschaft | Wert |
|-------------|------|
| **Typ** | Grafische Oberfläche für MS-DOS |
| **Entwickler** | Microsoft |
| **Erstveröffentlichung** | 20. November 1985 |
| **Support-Ende** | 31. Dezember 2001 |
| **Lizenz** | Proprietär |
| **Voraussetzung** | MS-DOS 2.0+, 256 KB RAM |

## Zusammenfassung

Windows 1.0 war Microsofts erster Versuch einer grafischen Benutzeroberfläche für MS-DOS. Anders als spätere Versionen waren keine überlappenden Fenster möglich – nur gekachelte Anordnung.

### Einschränkungen durch Apple

Aufgrund eines Lizenzabkommens mit Apple (wegen der Macintosh-Ähnlichkeit) durfte Windows 1.0 keine überlappenden Fenster verwenden. Erst Windows 2.0 führte diese ein.

### Mitgelieferte Programme

- **MS-DOS Executive**: Dateimanager
- **Calendar**: Kalender
- **Cardfile**: Karteikarten
- **Notepad**: Texteditor
- **Paint**: Malprogramm
- **Calculator**: Taschenrechner
- **Clock**: Uhr
- **Reversi**: Spiel

### Rezeption

Windows 1.0 war kein kommerzieller Erfolg. Es war langsam, benötigte teure Hardware und bot wenig Vorteile gegenüber DOS-Anwendungen. Erst Windows 3.0 (1990) erreichte Massenmarkt-Akzeptanz.
