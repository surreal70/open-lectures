# Windows 98

| Eigenschaft | Wert |
|-------------|------|
| **Typ** | 32-bit Hybrid-Betriebssystem |
| **Entwickler** | Microsoft |

| **Codename** | Memphis |

## Zusammenfassung

Windows 98 war die Weiterentwicklung von Windows 95 mit verbesserter Hardware-Unterstützung, Internet-Integration und dem Active Desktop. Die Second Edition (SE) behob viele Stabilitätsprobleme und wurde zum ausgereiftesten DOS-basierten Windows.

### Neuerungen gegenüber Windows 95

| Feature | Beschreibung |
|---------|--------------|
| **USB-Support** | Vollständige USB 1.1-Unterstützung |
| **FAT32** | Standard-Dateisystem |
| **Active Desktop** | Web-Integration |
| **IE 4/5** | Fest integriert |
| **DVD** | DVD-ROM-Unterstützung |
| **Multi-Monitor** | Mehrere Bildschirme |

### Der berühmte Blue Screen

Auf der COMDEX 1998 demonstrierte Bill Gates Windows 98 – und erlebte einen Live-BSOD bei der Plug-and-Play-Demo eines Scanners. "That must be why we're not shipping Windows 98 yet."

### Windows 98 SE

Die Second Edition (Mai 1999) brachte:
- Internet Explorer 5.0
- Internet Connection Sharing (ICS)
- DirectX 6.1
- Windows Media Player 6.2
- Verbesserte Stabilität
- WDM-Treiber-Verbesserungen

### Legacy

Windows 98 SE war bis weit in die 2000er beliebt für:
- Ältere Spiele und Hardware
- DOS-Anwendungen
- Systeme ohne NT-Anforderungen
