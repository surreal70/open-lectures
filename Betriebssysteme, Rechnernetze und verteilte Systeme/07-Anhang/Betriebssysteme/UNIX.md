# UNIX

## Kurzinfo

| Eigenschaft | Wert |
|-------------|------|
| **Typ** | Multiuser, Multitasking |
| **Erstveröffentlichung** | 1969 |
| **Entwickler** | Ken Thompson, Dennis Ritchie (Bell Labs) |
| **Geschrieben in** | Assembler, ab 1973 C |
| **Lizenz** | Proprietär (urspr.), diverse |

## Beschreibung

UNIX ist das einflussreichste Betriebssystem der Computergeschichte. Entwickelt bei AT&T Bell Labs als Reaktion auf das gescheiterte MULTICS-Projekt. Die Portierung nach C (1973) ermöglichte die Verbreitung auf verschiedene Hardware-Plattformen.

**UNIX-Philosophie:**
- "Do one thing and do it well"
- "Everything is a file"
- Pipes zur Programmverkettung (`|`)
