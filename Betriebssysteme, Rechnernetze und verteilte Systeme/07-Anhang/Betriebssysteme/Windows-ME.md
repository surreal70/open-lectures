# Windows ME (Millennium Edition)

## Überblick

| Eigenschaft | Wert |
|-------------|------|
| **Typ** | 32-bit Hybrid-Betriebssystem |
| **Entwickler** | Microsoft |
| **Erstveröffentlichung** | 14. September 2000 |
| **Support-Ende** | 11. Juli 2006 |
| **Lizenz** | Proprietär |
| **Codename** | Millennium |

## Zusammenfassung

Windows ME war die letzte Version der DOS-basierten Windows-Linie. Trotz neuer Features wie System Restore galt es wegen Stabilitätsproblemen als Fehlschlag und wurde schnell von Windows XP abgelöst.

### Neuerungen

| Feature | Beschreibung |
|---------|--------------|
| **System Restore** | Systemwiederherstellung |
| **Windows Media Player 7** | Neue Medien-Zentrale |
| **Movie Maker** | Video-Bearbeitung |
| **Automatische Updates** | Windows Update |
| **Heimnetzwerk-Assistent** | Vereinfachte Netzwerkeinrichtung |

### Entfernte Features

Microsoft entfernte den Zugang zur DOS-Kommandozeile:
- Kein "Restart in MS-DOS Mode"
- COMMAND.COM stark eingeschränkt
- Real-Mode-DOS-Treiber entfernt

Dies sollte die Stabilität verbessern, entfernte aber Kompatibilität mit älteren Programmen.

### Vermächtnis

Windows ME gilt als eines der schlechtesten Windows-Versionen. Es war ein Übergangsprodukt – die Zukunft lag bei Windows NT/2000/XP mit echtem 32-bit-Kernel ohne DOS-Altlasten.
