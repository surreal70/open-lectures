# Betriebssysteme-Referenz

Diese Sammlung enthält Kurzprofile aller im Vault erwähnten Betriebssysteme mit Quellenverweisen.

---
author: Andreas Hümmer

## Unix-Familie

### Ursprünge
- [[MULTICS]] - Vorläufer von UNIX (MIT/Bell Labs/GE, 1969)
- [[UNIX]] - Das Original (Bell Labs, 1969)
- [[Minix]] - Lehrsystem, inspirierte Linux (Tanenbaum, 1987)

### BSD-Varianten
- [[BSD]] - Berkeley Software Distribution (UC Berkeley, 1977-1995)
- [[FreeBSD]] - Server und Embedded (1993)
- [[OpenBSD]] - Sicherheitsfokus (1996)
- [[NetBSD]] - Portabilität (1993)
- [[DragonFly-BSD]] - HAMMER-Dateisystem (2004)

### System V und Derivate
- [[System-V]] - AT&T Unix (1983)
- [[Solaris]] - Sun/Oracle (1992) - ZFS, DTrace
- [[AIX]] - IBM POWER (1986)
- [[HP-UX]] - Hewlett-Packard (1984)
- [[IRIX]] - Silicon Graphics (1988)
- [[Xenix]] - Microsoft/SCO (1980)
- [[SINIX]] - Siemens (1984)
- [[SCO-Unix]] - PC-Unix (1989)

### Linux
- [[Linux]] - Freier Unix-Kernel (Torvalds, 1991)

## Microsoft Windows

### DOS-Ära
- [[MS-DOS]] - Microsoft Disk Operating System (1981)
- [[Windows-1]] - Erste GUI für DOS (1985)
- [[Windows-3]] - Durchbruch (1990)

### DOS-basierte Consumer-Linie
- [[Windows-95]] - Startmenü, 32-bit (1995)
- [[Windows-98]] - USB, FAT32 (1998)
- [[Windows-ME]] - Letzte DOS-Version (2000)

### NT-Linie
- [[Windows-NT]] - Enterprise-Kernel (Cutler, 1993)
- [[Windows-2000]] - Active Directory (2000)
- [[Windows-XP]] - Vereinigung Consumer/Enterprise (2001)
- [[Windows-Vista]] - Sicherheitsumbau (2007)
- [[Windows-7]] - Verfeinertes Vista (2009)
- [[Windows-10]] - Windows as a Service (2015)
- [[Windows-11]] - Neues Design (2021)
