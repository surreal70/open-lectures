# BSD (Berkeley Software Distribution)

## Überblick

| Eigenschaft | Wert |
|-------------|------|
| **Typ** | Unix-Betriebssystem |
| **Entwickler** | UC Berkeley (CSRG) |
| **Erstveröffentlichung** | 1977 (1BSD) |
| **Letzte Version** | 4.4BSD-Lite2 (1995) |
| **Lizenz** | BSD-Lizenz |
| **Einfluss** | FreeBSD, OpenBSD, NetBSD, macOS |

## Zusammenfassung

BSD entstand als Erweiterung von AT&T UNIX an der University of California, Berkeley. Die Computer Systems Research Group (CSRG) unter Bill Joy entwickelte zahlreiche Innovationen, die später in alle Unix-Systeme übernommen wurden.

### Wichtige Beiträge

- **TCP/IP-Stack**: Referenzimplementierung für das Internet
- **Virtual Memory**: Effiziente Speicherverwaltung
- **Fast File System (FFS)**: Verbesserte Dateisystem-Performance
- **vi-Editor**: Bis heute weit verbreitet
- **C-Shell (csh)**: Alternative zur Bourne Shell
- **Sockets-API**: Standard für Netzwerkprogrammierung

### Versionsgeschichte

| Version | Jahr | Neuerungen |
|---------|------|------------|
| 1BSD | 1977 | Pascal-Compiler, ex-Editor |
| 2BSD | 1978 | vi, C-Shell |
| 3BSD | 1979 | Virtual Memory |
| 4.2BSD | 1983 | TCP/IP, FFS |
| 4.3BSD | 1986 | Netzwerk-Verbesserungen |
| 4.4BSD | 1993 | Neu geschriebener, AT&T-freier Code |

### BSD-Lizenz

Die permissive BSD-Lizenz erlaubt kommerzielle Nutzung ohne Offenlegungspflicht des Quellcodes - im Gegensatz zur GPL. Dies ermöglichte die Verwendung in proprietären Systemen wie macOS.
